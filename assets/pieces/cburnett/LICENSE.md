# Piece set "cburnett"

Chess piece artwork by **Colin M.L. Burnett**
(https://en.wikipedia.org/wiki/User:Cburnett).

The SVG files in `svg/` were taken unmodified from the Lichess source repository
(https://github.com/lichess-org/lila, directory `public/piece/cburnett`).
The `COPYING.md` of that repository lists this piece set as **GPLv2+**
(GNU General Public License, version 2 or later; https://www.gnu.org/licenses/gpl-2.0.txt).

The PNG files in this directory are rasterized versions of those SVGs, created with
`tools/render_pieces.sh`. They are derived from the SVGs and are therefore under the same license.

Because that license allows the use under "version 2 or later", this project uses the pieces under
the terms of the **GNU General Public License, version 3 or later**, the same terms as the rest of the project
(see `LICENSE.md` in the root directory).
